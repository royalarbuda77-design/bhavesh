# 📘 StudyFlow — Colourful Study Timetable & Planner

A vibrant, all-in-one study app: weekly timetable, task manager, Pomodoro focus timer,
exam countdowns, quick notes, analytics, achievements and 6 gorgeous colour themes.
Everything runs offline in the browser — no account, no server, no tracking.

## ✨ Features

| Area | What you get |
|---|---|
| **Dashboard** | Live greeting, today's schedule with a "NOW" indicator, daily goal ring, XP/level bar, 7-day chart, next-exam countdown, quote of the day, one-tap task completion |
| **Timetable** | Colour-coded weekly grid (click any empty hour to add a block) + day list view, drag-free editing, duplicate block, copy a whole day, clear a day, print-friendly layout |
| **Tasks** | Quick add, priorities, due dates, subject tags, search, filters (All / Open / Today / Overdue / Done), sorting, overdue highlighting, confetti on completion |
| **Focus Timer** | Full Pomodoro cycle (focus / short break / long break), configurable durations & rounds, animated progress ring, tab-title countdown, chime, per-subject logging, manual time logging, today's log |
| **Subjects** | CRUD subjects with 12-colour palette, teacher, weekly hour target + progress, per-subject stats |
| **Exams** | Countdown cards with urgency colours, preparation bars, syllabus notes, past-exam archive |
| **Notes** | Colourful sticky notes, pin to top, search, subject filter |
| **Analytics** | 30-day bar chart, weekly rhythm, time-by-subject split, 12-week consistency heatmap, level progress, 10 unlockable achievements |
| **Settings** | 6 themes (Galaxy, Ocean, Sunset, Forest, Candy, Midnight), dark/light mode, 12/24h clock, sound toggle, daily goal, timetable hours, Pomodoro config, JSON export/import, demo data, wipe |

Plus: animated aurora background, glassmorphism UI, confetti, toasts, streaks, XP levels,
full keyboard-friendly modals, and a responsive layout with a mobile bottom nav.

## 🚀 Run it

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # production build in dist/
npm run preview
```

## 🧱 Stack

React 19 · Vite · Tailwind CSS · localStorage persistence · zero UI dependencies (icons are hand-rolled SVGs).
