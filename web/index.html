🎤 Voice flow (demo એ જ app નું architecture છે)

1️⃣ Wake — AudioGate (mic energy, duty-cycled) 100ms windows સાંભળે; speech plausible લાગે તો constrained ASR burst થી “jarvis” verify.
2️⃣ Listen — full STT session (gu/hi/en phrases boost).
3️⃣ Offline router — 40+ commands <80ms, zero network.
4️⃣ Gemini agent — બાકીનું JSON actions માં parse → controllers ચલાવે; chat answer SSE stream થી વાક્ય-દર-વાક્ય બોલાય.
5️⃣ Memory — વાત + facts + aliases Contextual Memory માં (on-device).

🛡️ Privacy

Wake + offline commands ૧૦૦% ફોનમાં. Cloud ફક્ત તમે command આપો એટલે, ફક્ત text — Gemini key AndroidKeyStore માં. Ads/analytics શૂન્ય.

શું શું કરી શકે — કમાન્ડ નમૂના

Modular આર્કિટેક્ચર

5 Gradle modules — દરેક સ્વતંત્ર રીતે test-યોગ્ય; :core માં કોઈ Android-framework heavy dependency નથી.

:core

State bus · AES-GCM keystore crypto · settings · trilingual offline NLU + lexicon · Self-Healing runtime · conversation + user memory

:gemini

OkHttp: generateContent, SSE stream (sentence-wise), vision (screenshot), agent JSON-decide, cloud TTS (24kHz PCM). AQ.… + AIza… keys ✓

:voice

AudioGate (energy + duty-cycle) · constrained ASR wake verify · SttEngine sessions · System+Cloud TTS manager · procedural SFX

:automation

Settings/App/Media/Call/Message/Clock/Reminder/Calendar/DeviceReport/Notification controllers · accessibility gestures+screen · CommandRouter

:app

Foreground service (mic type, Android 14 ready) · Overlay HUD service · Compose UI ૭ screens · boot/widget/DI

utterance ─► wake-verify ─► OfflineNlu/CommandRouter ─► action + 1-line speech (offline, 0ms net) └─else──► Gemini agentDecide(JSON actions) ─► CommandRouter ─► speech └─else──► Gemini chat SSE ─► sentences ─► TtsManager (system ⇄ cloud auto-fallback) JarvisBus events ─► notification · HUD overlay · UI screens · watchdog | SelfHealing ─► ક્યાંય crash નહીં
